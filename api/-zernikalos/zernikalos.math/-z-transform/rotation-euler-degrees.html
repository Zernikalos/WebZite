Zernikalos/zernikalos.math/ZTransform/rotationEulerDegrees

rotationEulerDegrees

var rotationEulerDegrees: ZEuler(source)

Like rotationEuler but ZEuler.roll, ZEuler.pitch, and ZEuler.yaw are expressed in degrees on this API surface only. The returned ZEuler still uses the same fields as radian-backed ZEuler elsewhere—do not pass this value to APIs that expect radians (e.g. ZQuaternion.fromEuler) without converting via Angles.degreesToRadians per component or use rotationEuler instead.

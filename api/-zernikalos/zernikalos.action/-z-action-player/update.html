fun update()(source)

Updates playback using elapsed wall time since the last call (seconds), then commits the sampled pose to skeleton.

fun update(deltaTimeSeconds: Float)(source)

Advances playback by deltaTimeSeconds (scaled by playbackSpeed when playing), then commits the sampled pose to skeleton. Use for fixed-step or injected delta time instead of wall-clock update.

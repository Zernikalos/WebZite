sampleAt

fun sampleAt(time: Float): ZKeyFrame(source)

Evaluates all tracks at time and returns a sampled ZKeyFrame (bone id → partial local overrides). Does not read or modify the runtime skeleton.

Return

A new keyframe instance holding the evaluated pose samples.

Parameters

time

Sample time in seconds, usually within [0, duration].

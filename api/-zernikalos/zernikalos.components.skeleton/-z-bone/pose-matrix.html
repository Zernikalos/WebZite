Zernikalos/zernikalos.components.skeleton/ZBone/poseMatrix

poseMatrix

var poseMatrix: ZMatrix4(source)

Returns the world pose matrix of this bone for the current frame (rest or animated).

Populated when the host applies a sampled clip via zernikalos.objects.ZSkeleton.applyKeyFrame (typically after zernikalos.action.ZActionPlayer.update) or when the model commits the rest pose at initialization.
